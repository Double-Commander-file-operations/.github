# Double Commander - Dual Panel File Manager for Windows

## About Double Commander

Double Commander is a dual panel file manager built for people who want both source and target folders visible at once. Instead of dragging windows around or losing track of where a file came from, Double Commander file manager keeps two directories side by side and lets you copy, move, rename, delete, and compare without leaving the keyboard. It is often described as a Total Commander alternative, and that comparison is fair: the layout, the function key row, and the focus on fast file operations all point in the same direction. Double Commander dual panel design means you always see where things are going before anything changes. Double Commander file operations are built to be predictable, so a large reorganization stays understandable from the first move to the last.

## Overview

Double Commander turns file management into a two-pane workspace. The left panel and the right panel each show a directory, and the active panel is always clear. You can copy from one side to the other, compare folders, sync trees, or open archives as if they were plain directories.

Because Double Commander file manager follows familiar keyboard conventions, users coming from older dual-pane tools feel at home quickly. Because it is also a Total Commander alternative with its own plugin and configuration system, users who want to tune behavior can go deep without breaking the basics. Double Commander dual panel layout is not a gimmick; it is the core idea that makes Double Commander file operations faster than juggling separate Explorer windows.

The result is a file manager that works for quick daily tasks and for long, careful cleanup sessions alike.

## Starting with Double Commander

1. **Open Double Commander** – Launch the file manager and note which panel is active.
2. **Set both panels** – Point the left and right panels at the folders you want to work with.
3. **Select files** – Use the keyboard or mouse to mark the items you plan to act on.
4. **Run a file operation** – Copy, move, or rename between panels and watch the progress dialog.
5. **Compare if needed** – Use folder comparison before syncing two trees.
6. **Adjust settings** – Tune columns, colors, and shortcuts once the basics feel natural.
7. **Repeat** – Keep both panels pointed at your working directories for the next task.
